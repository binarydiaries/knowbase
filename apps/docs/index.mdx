## How Agenvik is organized

<Steps>
  <Step title="Agents">
    Agents are the assistants you create for different teams, products, or customer journeys.
  </Step>
  <Step title="Knowledge Sources">
    Knowledge Sources contain the content your agent uses when answering questions — text, Q&A pairs, PDFs, and website URLs.
  </Step>
  <Step title="Behaviour">
    Behaviour controls instructions, tone, verbosity, fallback message, and guardrails.
  </Step>
  <Step title="Channels and Actions">
    Channels decide where the agent appears.{/* LEAD_GENERATION_DISABLED: original text was "Actions let the agent collect useful information, such as leads." — restore when re-enabling */}
