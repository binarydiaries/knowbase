## Content Conventions Used in These Files

- `[PLACEHOLDER: description]` — needs real data (metrics, photos, testimonials)
- `[ILLUSTRATION: description]` — visual/graphic needed here
- `[CTA]` — call to action button
- `---` between sections marks a visible page section break
- Headings follow H1 > H2 > H3 hierarchy per page
- Every section has: headline, supporting copy, and a clear purpose note
