Plans determine which features are available and how many resources your workspace can use.

## What you will learn

- Which areas can be limited by plan
- How locked and disabled states work
- Where to review usage
- What to do when a limit is reached

## Common limits

Agenvik can show limits for:

- Active Agents
- Knowledge Sources
- Monthly Messages
- Daily Training
- Analytics access
- WhatsApp integration
- Lead Generation

## Locked and disabled states

When a limit is reached, Agenvik may disable actions such as creating Agents, adding sources, starting training, restoring archived Agents, or enabling paid features.

<Frame>
  <img src="/images/placeholders/disabled-tooltip.png" alt="Disabled tooltip placeholder" />
</Frame>

## What to do when you reach a limit

- Archive unused Agents if you reached the active Agent limit
- Delete outdated Knowledge Sources if you reached the source limit
- Wait until the daily training reset if training runs are used
- Review **Usage** to understand message volume
- Upgrade when the workspace needs more capacity or paid features
