## SECTION 6 — FAQ (E-commerce specific)

**Q: My store uses Shopify. How do I add the widget?**
A: Paste the embed snippet in your Shopify theme's `theme.liquid` file before the closing `</body>` tag. It takes about 2 minutes. We have a step-by-step guide for Shopify, WooCommerce, and other major platforms.

**Q: My inventory and order status change constantly. Can the agent handle that?**
A: For dynamic order status (specific order tracking), the agent needs access to your order data via API — that integration is on our roadmap. For now, the agent handles policy and product questions. For order tracking, it can direct customers to your tracking page or order email.

**Q: What about peak seasons when query volume spikes?**
A: Your message plan determines how many conversations per month. If you expect a spike (Diwali, end-of-year sales), upgrade your plan before the event and downgrade after. No long-term commitment.

**Q: Can it upsell or cross-sell?**
A: Not actively — it answers questions rather than proactively recommending. However, you can include product recommendations in your knowledge base: "If a customer asks about [Product A], also mention [Product B] as a complementary product." The agent will follow that instruction.
