**Usage** shows how your workspace consumes messages and knowledge resources.

## What you will learn

- Which usage metrics are available
- How to filter usage by Agent and date
- How to use usage charts for planning

## Open Usage

Open **Usage** from the sidebar.

<Frame>
  <img src="/images/placeholders/usage-dashboard.png" alt="Usage dashboard placeholder" />
</Frame>

## Review usage cards

The overview cards summarize workspace-level usage. Use them to understand current consumption before reviewing the charts.

<Frame>
  <img src="/images/placeholders/usage-stat-cards.png" alt="Usage stat cards placeholder" />
</Frame>

## Filter by Agent and date

Use the header filters to select all Agents or one Agent. Choose a date range to compare short-term and month-to-date activity.

<Frame>
  <img src="/images/placeholders/usage-filters.png" alt="Usage filters placeholder" />
</Frame>

## Messages over time

Use **Daily Messages** to understand traffic patterns. Spikes can indicate campaigns, support incidents, or successful deployments.

<Frame>
  <img src="/images/placeholders/daily-messages-chart.png" alt="Daily Messages chart placeholder" />
</Frame>

Use **Messages by Agent** and **Knowledge by Agent** to understand which Agents are active and which ones have the most source content.
