Use this checklist before you make an Agent available to visitors.

## What you will learn

- Which dashboard settings to verify
- How to test the Agent before launch
- What to monitor after launch

## 1. Confirm Knowledge Sources

Open the Agent and review **Knowledge Sources**. Make sure sources are current, titled clearly, and trained.

<Frame>
  <img src="/images/placeholders/knowledge-source-list.png" alt="Knowledge Source list launch check placeholder" />
</Frame>

## 2. Confirm Behaviour

Review **System Prompt**, **Tone**, **Verbosity**, **Fallback Message**, and **Guardrails**.

<Frame>
  <img src="/images/product-ss/behaviour-settings.png" alt="Behaviour launch check placeholder" />
</Frame>

## 3. Confirm Channel text and color

Review **Display Name**, **Subtitle**, **Welcome Message**, **Input Placeholder**, and **Primary Color**.

<Frame>
  <img src="/images/product-ss/web-channel-settings.png" alt="Web Channel launch check placeholder" />
</Frame>

## 4. Test in Web Preview

Ask questions that represent real visitor intent. Include simple, ambiguous, unsupported, and follow-up questions.

<Frame>
  <img src="/images/product-ss/agent-preview.png" alt="Web Preview launch check placeholder" />
</Frame>

## 5. Enable Actions if needed

If the Agent should collect contact details, enable and configure **Lead Generation** before launch.

<Frame>
  <img src="/images/placeholders/lead-generation-config.png" alt="Lead Generation launch check placeholder" />
</Frame>

## 6. Install and verify

Install the widget snippet, publish the website, and confirm a test conversation appears in **Conversations**.

<Frame>
  <img src="/images/placeholders/live-widget.png" alt="Live widget launch check placeholder" />
</Frame>
