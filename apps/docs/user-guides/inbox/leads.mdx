**Leads** lists the contact details captured by Agents with Lead Generation enabled.

## What you will learn

- How to review captured leads
- How to filter leads by Agent
- How to open the source conversation
- Why Leads may be unavailable

## Check access

Lead Generation is available on Starter and above. If your workspace is on the free plan, the Leads page shows an upgrade prompt.

<Frame>
  <img src="/images/placeholders/leads-locked.png" alt="Leads locked state placeholder" />
</Frame>

## Review leads

Open **Leads** from the sidebar. The table can show name, email, phone, company, Agent, Channel, captured time, and the linked conversation.

<Frame>
  <img src="/images/product-ss/leads-table.png" alt="Leads table placeholder" />
</Frame>

## Filter by Agent

Use the Agent filter in the header to focus on one Agent or review all Agents.

<Frame>
  <img src="/images/placeholders/leads-agent-filter.png" alt="Leads Agent filter placeholder" />
</Frame>

## Open the conversation

Use the conversation link to understand what the visitor asked before sharing contact information.

<Frame>
  <img src="/images/placeholders/lead-conversation-link.png" alt="Lead conversation link placeholder" />
</Frame>

## No leads yet

If the page is empty, check that:

- Lead Generation is enabled on the Agent
- The Agent is live on a Channel
- Visitors are reaching the Agent
- The conversation naturally asks for contact information
