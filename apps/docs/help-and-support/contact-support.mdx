If troubleshooting does not resolve the issue, contact support with enough detail to reproduce the problem.

## What to include

Send:

- Your workspace name
- The Agent name
- The page or Channel affected
- What you expected to happen
- What actually happened
- Screenshot or screen recording, if available
- Approximate time the issue happened

## For Agent answer issues

Include:

- The exact user question
- The Agent's response
- The Knowledge Source you expected it to use
- Whether the Agent was trained after that source was added

  <img src="/images/placeholders/conversation-thread.png" alt="Conversation support context placeholder" />
</Frame>

## For widget issues

Include:

- The live website URL
- Where the snippet was installed
- Whether the issue happens on desktop, mobile, or both
- Whether the browser console shows errors

<Frame>
  <img src="/images/placeholders/widget-not-visible.png" alt="Widget support context placeholder" />
</Frame>

## For WhatsApp issues

Include:

- Whether WhatsApp Business is connected in **Integrations**
- The display phone number
- The Agent you tried to assign it to
- Whether the number is already assigned elsewhere
