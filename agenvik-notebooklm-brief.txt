TAGLINE
-------
Build AI-powered support chatbots trained on your knowledge — deployed across web, WhatsApp, and Slack in minutes.


WHAT IS AGENVIK?
----------------
Agenvik is a SaaS platform that lets any business create an AI chatbot trained on their own content.
You upload your documentation, FAQs, product info, or any text — and Agenvik trains an AI agent on it.
That agent can then answer customer questions accurately, 24/7, across multiple channels.

No AI expertise required. No coding required. Works out of the box.


WHO IS IT FOR?
--------------
- SaaS companies wanting to automate repetitive customer support questions
- E-commerce stores answering product and shipping FAQs
- Agencies building branded chatbots for clients
- Internal teams building knowledge assistants for HR, operations, or IT


THE CORE PROBLEM IT SOLVES
--------------------------
Businesses answer the same 20 questions thousands of times a year.
Their team wastes hours on repetitive queries.
They lose leads because no one is available after hours.
And generic AI chatbots like ChatGPT don't know anything specific about their product.

Agenvik solves this by letting businesses teach an AI exactly what it needs to know —
using their own content — and then deploying it everywhere their customers are.


HOW IT WORKS — THE SIMPLE FLOW
--------------------------------
Step 1: Create an agent (give it a name and description)
Step 2: Add knowledge sources (upload documents, paste text, add Q&A pairs, or crawl a URL)
Step 3: Click "Train" — Agenvik indexes and embeds all your content using AI
Step 4: Customize behavior (tone, verbosity, system prompt, fallback message)
Step 5: Enable channels (web widget, WhatsApp, Slack)
Step 6: Your agent is live — answering questions instantly

The entire setup takes less than 10 minutes.


KNOWLEDGE SOURCES (What you can upload)
-----------------------------------------
Agenvik supports 4 types of knowledge sources:

1. TEXT — Plain text input, up to 10,000 characters
   Use for: About us pages, policies, product descriptions

2. Q&A — Up to 50 question-answer pairs (20,000 chars total)
   Use for: FAQs, common support tickets, sales objections

3. PDF — File upload up to 50MB, fully parsed and indexed
   Use for: Product manuals, documentation, reports, whitepapers

4. URL — Crawl a web page and extract its content automatically (premium feature)
   Use for: Help center articles, blog posts, landing pages

Each document goes through a status pipeline:
Ready → Queue → Indexing → Indexed (or Failed if there's an error)

The agent only answers from indexed sources — it never hallucinates beyond what you gave it.


AGENT BEHAVIOR CUSTOMIZATION
------------------------------
Each agent has a Behavior configuration with:

- System Prompt: The core instruction to the AI (20-500 chars)
  Default: "You are a helpful support assistant. Answer using the provided sources only."

- Tone: friendly / professional / neutral
  Controls how the agent communicates with users

- Verbosity: short / balanced / detailed
  Controls how long the agent's answers are

- Fallback Message: What the agent says when it doesn't know (5-120 chars)
  Default: "I don't know the answer to that based on the information I have."

- Guardrails (optional): Hard constraints on what the agent must never do or say


CHANNELS — DEPLOY EVERYWHERE
------------------------------
One agent, multiple channels. Each channel is independently enabled/configured.

1. WEB WIDGET — Embed on any website
   Config options: Display name, subtitle, welcome message, suggestion questions (up to 6),
   input placeholder text, primary colour, allowed domains (whitelist), avatar image
   Deployment: Paste a script tag into your site HTML

2. WHATSAPP — Business messaging
   Connect your WhatsApp Business phone number
   Agent answers customer messages automatically
   Requires WhatsApp integration setup in Integrations page

3. SLACK — Workspace integration
   Two modes: "channel mode" (answers in a channel) or "mention mode" (answers when @mentioned)
   OAuth connection flow via Integrations page

4. INSTAGRAM — Direct messages (coming soon)

Channel statuses: inactive / active / error


CONVERSATIONS & ANALYTICS
---------------------------
Every conversation is stored and analysed.

Conversation data captured:
- Full message history (user + assistant turns)
- Channel source (web/WhatsApp/Slack)
- Country of the user (auto-detected)
- Topic of the conversation (AI-extracted)
- Entities mentioned (AI-extracted)
- Confidence score per message (how sure the AI was)
- Source documents used to answer (which chunks were retrieved)
- Sentiment per message (positive / neutral / negative)

Analytics dashboard shows (on paid plans):
- Total conversations and messages (all-time)
- Daily conversation trend chart
- Messages by channel (web vs WhatsApp vs Slack)
- Top agents by message count
- Sentiment breakdown (% positive / neutral / negative)
- Top topics across all conversations
- Country distribution of users
- Average confidence score
- Average messages per conversation

This tells businesses: what their customers are asking, how well the agent performs,
and where they need to add more knowledge.


LEAD GENERATION (Starter plan and above)
-----------------------------------------
The agent can capture lead information mid-conversation.

Lead fields captured:
- Name
- Email
- Phone
- Company
- Custom fields (extensible)

Leads are linked to the conversation where they were captured,
and to the channel and agent. Viewable in the Leads tab.


USAGE TRACKING
--------------
Each plan comes with hard limits tracked in real time:

- Active agents (number of agents you can create)
- Knowledge sources per agent
- Messages per month (across all channels)

The Usage page shows:
- Current usage vs limits for all four metrics

When a plan limit is hit, the agent is locked (read-only) until upgraded or the period resets.

TECHNICAL HIGHLIGHTS (for technical audiences)
------------------------------------------------
- RAG (Retrieval-Augmented Generation): Documents are chunked, embedded with OpenAI text-embedding-3-small,
  stored as vectors in PostgreSQL (pgvector). At query time, semantic search finds relevant chunks,
  which are injected as context into the LLM prompt.
- Streaming responses: Chat replies stream token by token for a fast, real-time feel
- Background processing: Document indexing runs in a BullMQ queue (async, non-blocking)
- Multi-tenancy: Every resource is scoped to an organisation (Clerk org ID)
- Self-improving: Each training run re-indexes all documents, picking up new content
